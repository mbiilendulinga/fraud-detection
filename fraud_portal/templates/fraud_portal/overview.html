What this does
An end-to-end fraud detection pipeline, not a notebook demo.

Each transaction flows through a feature engineering step that produces {{ features_used }} predictors — including how fast the client is transacting, whether the amount is unusual for them, whether they have ever used this device, and whether the transaction location matches their home province.

The model outputs a fraud probability. If it crosses the operational threshold ({{ threshold|floatformat:4 }}), the transaction is flagged. Every flagged transaction also gets a SHAP-based explanation showing which features pushed the score up and which pulled it down.

  • Raw data: 100,000 transactions, 5,000 clients, 1.7% fraud.
  • Feature engineering: 82 predictors, all temporally leak-free.
  • Models compared: Logistic Regression baseline vs XGBoost.
